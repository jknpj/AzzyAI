Downloads the LATAM data of the homunculus skills AzzyAI uses from the Divine Pride API.

Rust port of tools/harness/divinepride_sync.py: same flags, same output file and
byte-identical JSON (indent 1, sorted keys, UTF-8) for the same API answers.

The result goes to tools/harness/fixtures/divinepride_<server>.json (raw API
answers keyed by skill ID), so the official values in USER_AI/H_SkillList.lua can
be compared with what the LATAM client actually uses. The file holds third-party
data and is git-ignored; keep it local.

Usage (needs a free API key from your divine-pride.net profile page):
    set DIVINEPRIDE_API_KEY=<your key>
    divinepride-sync               # LATAM
    divinepride-sync --server kROM # another server
    divinepride-sync --refresh     # fetch again even if cached

Only the known homunculus skill IDs are requested (no ID enumeration), answers
already in the output file are reused, and 429 answers are retried after
Retry-After. The key is only read from the environment and sent to the API; it is
never printed or saved. Behind a proxy, set HTTPS_PROXY first.
