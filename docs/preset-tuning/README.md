# Default preset tuning: comparison tables

[Release notes](../RELEASE_NOTES.md#default-preset-tuning) | spreadsheets: [preset-before-after.csv](preset-before-after.csv), [preset-options.csv](preset-options.csv)

Generated by `python tools/harness/preset_report.py`; do not edit by hand. Every number is the expected value of an offline simulation (`tools/harness/damage.lua`): a zero-defense Neutral dummy for 180 s, the level 275 homunculi of `tools/harness/fixtures/homun_stats.lua`, rAthena data of the commit pinned in `fixtures/rathena.lua`, no SP refill. It is **not** a measurement on a server: the homunculus stats are hypothetical and the real DPS depends on the server (the RO LATAM homunculi are much stronger than rAthena's), so read the tables as a comparison between configurations, not as expected in-game DPS; only Sonic Claw and Xeno Slasher were checked against measured damage. DPS is expected damage per second; damage/SP is expected damage divided by the SP the casts spent. SP regeneration is 60 SP/s unless stated (Eleanor 22 SP/s, measured on the test server). Monsters are the same dummy, standing together in a pack.

## Limits

- Validated against measured damage only for Sonic Claw (Eleanor) and Xeno Slasher (Eira). The other skills use the same formulas but were never compared with the server.
- Magma Flow (Dieter) is priced as one splash hit per cast; the in-game buff that triggers on attacks is not modelled, so its rows understate or overstate it. Ground units (Lava Slide, Blast Forge) are priced as hitting every monster in the area on every tick for the whole duration.
- Status effects (Bleeding, Stun, Tinder Breaker's DEF reduction), buffs, the owner's skills and monster attacks are not modelled. The AI follows its skill-class priority, so these tables do not show what the best skill would be, only what the AI does with each configuration.
- No official-server data: skill values differ there, and the preset keeps `ServerType = SERVER_OFFICIAL`.
